# آرایشگاه ابراهیم

نمونهٔ اولیهٔ اندروید و سرور آنلاین برای یک آرایشگر. قیمت‌ها و ساعات کاری نمونه هستند. مشتری نیازی به حساب کاربری ندارد؛ در نتیجه پیش از انتشار عمومی، تأیید شماره و محدودسازی درخواست‌ها را اضافه کنید تا رزرو جعلی کاهش یابد. پنل مدیر شمارهٔ تماس و سوابق نوبت هر مشتری را نشان می‌دهد؛ پروندهٔ مستقل مشتری ندارد.

## اجرای آزمایشی سرور

در پوشهٔ server با Python 3.10 یا بالاتر:

```sh
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
export SALON_ADMIN_PASSWORD='یک رمز قوی و یکتا جایگزین کنید'
python app.py
```

سپس http://127.0.0.1:5000/ را باز کنید. پنل `/admin`، نام کاربری `admin` و رمز تعیین‌شده دارد. برای انتشار، به‌جای سرور توسعه از `waitress-serve --listen=127.0.0.1:8000 app:app` پشت پراکسی HTTPS استفاده کنید. `SALON_DB` را به مسیر دائمی و خصوصی تنظیم کنید. از پایگاه‌داده پشتیبان بگیرید و شماره‌ها را در گزارش عمومی نگه ندارید.

## ساخت APK

پوشهٔ android را با Android Studio، JDK 17 و SDK 35 باز کنید. در `android/gradle.properties` نشانی سرور عمومی HTTPS را با اسلش پایانی درج کنید؛ مثلاً `salonUrl=https://salon.example.com/`. سپس از منوی Build گزینهٔ ساخت APK را بزنید. برای انتشار عمومی از APK امضاشده استفاده کنید. WebView فقط به دامنهٔ سرور تعیین‌شده اجازهٔ پیمایش می‌دهد. در صورت نیاز به پنل در گوشی، لینک «ورود مدیر» را داخل همان برنامه بزنید.

## یادآوری‌ها

- اعلان: در Firebase یک اپ اندروید با بستهٔ `ir.ebrahim.salon` بسازید. مقادیر `mobilesdk_app_id`، `current_key`، `project_id` و `project_number` را به‌ترتیب در `android/app/src/main/res/values/firebase.xml` وارد کنید. سمت سرور `SALON_FIREBASE=1` و `GOOGLE_APPLICATION_CREDENTIALS` (مسیر فایل خصوصی کلید سرویس همان پروژه) را تعریف کنید. کلید سرویس را در APK یا مخزن نگذارید. مشتری باید از اپ اندروید با مجوز اعلان و توکن فعال رزرو کند؛ رزرو مرورگر وب فقط پیامک خواهد داشت. چرخش توکن برای نوبت‌های قبلی در این نسخه همگام نمی‌شود.
- پیامک: `SALON_SMS_WEBHOOK` را روی URL یک واسط HTTPS برای پنل پیامکی خود و `SALON_SMS_SECRET` را روی رمز مشترک بگذارید. واسط یک POST با JSON شامل `phone` و `message` دریافت می‌کند؛ هدر `Authorization: Bearer …` را اعتبارسنجی کند، `Idempotency-Key` را برای جلوگیری از ارسال تکراری ثبت کند و پس از پذیرش ارائه‌دهنده پاسخ 2xx بدهد. اتصال مستقیم به پنل خاصی در این پروژه وجود ندارد.
- فرمان `python app.py remind` را هر دقیقه با cron یا systemd timer، با همان مسیر پایگاه‌داده، محیط مجازی و متغیرهای سرور اجرا کنید. مقدار اولیه ۱۲۰ دقیقه است. نوبت لغوشده یادآوری جدید نمی‌گیرد و نوبت جابه‌جاشده برای ساعت جدید دوباره بررسی می‌شود؛ پیام ارسال‌شده قابل پس‌گرفتن نیست. ارسال به اتصال و تحویل سرویس‌دهنده وابسته است.

## وضعیت آزمایش

گردش رزرو، تداخل، مشاهدهٔ پنل، جابه‌جایی و لغو با کلاینت تست Flask بررسی شده‌اند. ساخت APK و تحویل واقعی پیامک و اعلان در این محیط آزمایش نشده است.
